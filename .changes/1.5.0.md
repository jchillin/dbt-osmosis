## 1.5.0 - 2026-07-05
### Added
* Expose maintained core feature modules through first-class CLI commands.

- Add `dbt-osmosis migration plan` for SQL, JSON, and Markdown migration plans generated from schema diffs.
- Add `dbt-osmosis validate models` for dry-run model validation with failure exit codes.
- Add `dbt-osmosis analyze docs`, `analyze style`, and `analyze discover` for documentation coverage checks, project voice/style analysis, and prioritized gap discovery.
